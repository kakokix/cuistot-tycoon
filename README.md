# Cuistot Tycoon

Jeu de gestion de restaurant : tu incarnes Chef Marcel et tu fais vivre « Chez Cuistot », du cœur de la jungle jusqu'à la grande ville.

Ce dépôt sert aussi de canal de mises à jour : les versions installées du jeu (Android, Windows) vérifient `update/version.json` et se mettent à jour toutes seules.
